# Aion Config

Программа для Windows: правит настройки клиента Aion (`system.cfg`) и файл переопределений `system.ovr`.

- **Анимации:** `g_blend_time`, `g_blendout_time` и задержки цепочек умений, с пресетами и своими строками
- **Графика:** уровни из меню, MRT, скрытые переключатели (пляжи, погода, отражения, лог чата…)
- **Звук:** громкость по категориям
- **Окно и камера:** разрешение, режим окна, дальность камеры
- **Все параметры:** любая строка `system.cfg`, плюс добавление и удаление строк
- **Что запишется:** предпросмотр файлов до сохранения

При первом сохранении рядом кладутся `system.cfg.editor-backup` / `system.ovr.editor-backup`, и кнопка «Вернуть как было» возвращает к ним.
Если клиент запущен, программа предупреждает: при выходе игра перезаписывает `system.cfg`.

## Обновления

Установщик и обновления лежат в GitHub Releases. Программа проверяет обновления при запуске и раз в 3 часа; кнопка «Обновить» скачивает новую версию и перезапускается.

Выпуск версии:

```
# поднять "version" в package.json, закоммитить в main
gh release create vX.Y.Z --target main --title vX.Y.Z --notes "что изменилось"
```

Тег запускает GitHub Actions (`.github/workflows/release.yml`), и тот собирает `Aion-Config-Setup-X.Y.Z.exe`, `latest.yml` и `.blockmap` в этот релиз.
Релиз нужно создавать заранее командой выше: если electron-builder создаёт релиз сам, получаются два релиза.

## Разработка

```
npm install
npm start            # окно программы
npm run selftest     # проверка разбора/сборки system.cfg
node tools/make-icon.js
```

Шрифты Onest и JetBrains Mono распространяются по лицензии SIL OFL (`src/ui/fonts`).
